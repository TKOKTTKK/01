这个包是给你部署到 Cloudflare 用的，作用两件事：
  1) 把 index.html 当静态页对外提供（就是你原来那份单文件，一个字没改）
  2) 把 /api/ /api2/ /api3/ 三个路径同源转发到 tronagg

为什么要转发：tronagg 不允许第三方网页跨域直连，页面直接 fetch 它的域名会被浏览器拦；
走同源转发就跟在原来那个站上跑完全一样，而且密钥可以只放在 Worker 里。

==================================================
方式一：Workers + wrangler（推荐，最省事）
==================================================
1. 解压后进入这个目录（worker.js、wrangler.toml、public/ 都在同级）
2. npm i -D wrangler
3. npx wrangler login
4. 存 key（不想用 secret 可以跳过，前端自带的 key 会被透传）：
     npx wrangler secret put TRONAGG_KEY
5. npx wrangler deploy
6. 输出里会有一个 https://tron-pay.<你的子域>.workers.dev 地址，打开就是你的页面

==================================================
方式二：控制台建 Worker
==================================================
1. Workers & Pages -> 创建 -> Worker
2. 编辑代码，把 worker.js 的全部内容粘进去，Deploy
3. Settings -> Variables and Secrets，加一个 Secret：TRONAGG_KEY = 你的 key
4. Settings -> 静态资源（Assets），绑定名填 ASSETS，指向 index.html 所在目录
   （控制台上传静态文件比较绕，能用方式一就用方式一）

==================================================
方式三：Cloudflare Pages（拖拽/上传）
==================================================
1. 准备一个输出目录，把 public/index.html 放进去
2. 把本包的 worker.js 复制一份改名成 _worker.js，放在 index.html 同级
3. 整个目录上传到 Pages（或者 git push 让它自动构建）

==================================================
换 key
==================================================
方式一：npx wrangler secret put TRONAGG_KEY 重设一次，再 deploy
方式二：控制台 Secrets 里改
index.html 不用动，也不用重新上传。

==================================================
确认转发通了没
==================================================
浏览器打开（前提是已经配好 TRONAGG_KEY）：
  https://<你的域名>/api3/?resource_amount=100400&duration=1h
应该返回一段 JSON，里面有 "total_price_trx":"1.8072" 之类。
返回 404 或 HTML，说明转发没生效，回去检查 worker 有没有接管 /api3/ 这个路径。

==================================================
备注
==================================================
- 前端还在用 /api/ 下单、/api2/ 查订单，路径不用改。
- tronagg 的 key 建议只放少量 TRX，定期换。
- 「一个地址只租一次」目前记在访客浏览器 localStorage；要按地址彻底封死需要服务端存储
  （Cloudflare 可以用 KV），需要的话跟我说。
