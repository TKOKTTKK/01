Imported or restored a wallet but can't find your tokens?

Updated at 2026-11-13

If your tokens do not appear after importing a mnemonic phrase or private key into imToken, first check the account network, then confirm that the imported address matches your original address.

1. Check the Account Network

Make sure your current account is on the network where your tokens were originally held. Networks such as Ethereum, Arbitrum, and Base use the same address format within a wallet, but tokens are recorded separately on each network.

If the network does not match, add or switch to the correct network account. Learn more: What Is an Account?

2. Check the Wallet Address

The Addresses Match

If both the network and address match, the tokens may simply not be displayed on the homepage.

Tap “+” on the account homepage and add the token using one of these methods:

  • Select it under “All My Assets” or “Popular Assets”;
  • Search for its name or contract address;
  • Enter its contract address using the “Custom Token” feature.

👉 See the guide: How to manage and add tokens in imToken?

The Addresses Do Not Match

Check the following:

  • Wrong mnemonic phrase or private key: If you have multiple mnemonic phrases or private keys, find the backup for the wallet you want to restore and import it again;
  • Backup or entry error: An incorrectly recorded or entered mnemonic phrase or private key may generate a different address. Check it carefully and import it again;
  • The correct derived account has not been restored: If you added multiple accounts using the same mnemonic phrase, you need to restore the corresponding derived address. For TRON, tap the three dots in the top right corner of the network icon on the Add Account page, then enter “Advanced” to add the account. Learn more: How to add derived accounts in imToken?
  • Different mnemonic derivation path: If your mnemonic phrase was generated by another wallet app, its address type or derivation path may differ from imToken’s default settings. Confirm these details and restore the wallet in the original app.
